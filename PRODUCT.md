# Product

## Problem

Legal-document drafting requires coordinated field propagation, source traceability, and court-readable output that ordinary static templates do not expose clearly.

## Users and jobs

- Legal professionals and reviewers need to fill repeated facts once and see them propagate consistently.
- Reviewers need to understand which authorities and source memos support each section.
- Demonstration users need to explore editing and print behavior without installing a toolchain.

## Outcomes

- A user can complete, inspect, revise, and print the demo motion from one browser surface.
- Authorities and derivations remain traceable to the relevant document sections.
- Authored reference memos regenerate deterministically into the browser projection.

## Scope

- Static browser application, one demonstration motion, fill/read/edit modes, citation map, reference reader, and print CSS.
- Committed source memos and a local Node-based reference projection.

## Non-goals

- Providing legal advice or replacing licensed-attorney review.
- Filing documents, managing client records, or mutating production services during repository verification.
